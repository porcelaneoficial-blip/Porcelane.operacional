# PORCELANE

Aplicativo novo e independente de operação e gestão para marmorarias.

> **Importante:** este projeto é paralelo ao sistema PORCELANE antigo em produção. Não alterar, sobrescrever, excluir ou migrar o sistema antigo por este repositório.

## Ecossistema

`PORCELANE (interface) → PETRA (motor de gestão) → banco/storage → integrações`

## Módulos

Dashboard; Comercial; Operação; Financeiro; Estoque; RH; Documentos; Portal do Cliente; Portal do Funcionário; Assistente; Configurações e Integrações.

## Regra crítica

**Sem medição registrada com data e aprovada/conferida, a ordem de corte/produção permanece bloqueada.**

**Pedido encerrado não pode ser alterado diretamente.**

## Tecnologia

React + TypeScript + Vite, com interface responsiva e preparada para PWA.

## Desenvolvimento econômico

O código deve ser preparado e versionado no GitHub. O Bolt deve entrar apenas quando necessário para importar/conectar, visualizar, ajustar pontualmente ou publicar, evitando geração repetida e consumo desnecessário de créditos.
